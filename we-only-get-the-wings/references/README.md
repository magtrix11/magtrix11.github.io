# Mood-Board References — 42 Pins

The mood board contains **42 individual pin references**. They are documented across 11 supplied, overlapping screen captures in `moodboard_raw/`. The number of screenshot files is not the number of visual references. `moodboard_contact_sheet.jpg` presents all 11 captures together for orientation.

These pins are visual research, not a set of final production assets to copy. Inspect every capture and every distinct pin inside it. Account for overlap and repeated pins between adjacent captures. Extract formal properties: color relationships, texture, density, silhouette, layering, translucency, bodily ambiguity, material construction, movement potential, and spatial composition. When discussing an observation, cite the capture filename plus the pin's visible position within that capture.

Do not reproduce a contemporary artist's specific composition or a historical object's exact design. Use references to understand a visual and material grammar. Any later direct art-historical reference should be researched, documented, and handled with cultural specificity.

The Pinterest link in `PINTEREST_BOARD.md` is supplemental. Do not make access to Pinterest a prerequisite for the work.
