# Output

Use this directory for review frames, contact sheets, draft movies, and final renders. Keep generated output out of the source and reference folders.

- `study01/contact_sheet.jpg`: 9 labelled key frames from Study 01 (seed 1127, 1920×1080).
- `study01/keyframes/`: the same frames at full resolution.
- `study01/study01_1080.mp4`: the 10 s review movie.
- `study01/render.json`: seed, size and strip-role assignment of the render.

Full PNG sequences go to `../renders/` (git-ignored).
