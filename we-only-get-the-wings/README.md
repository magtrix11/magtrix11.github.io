# We Only Get the Wings — Claude Code Handoff

This folder is the complete starting package for developing the moving-image work in Claude Code.

## Open first

1. Read `START_HERE.md`.
2. Open this whole folder in Claude Code.
3. Paste the complete contents of `PASTE_INTO_CLAUDE_CODE.txt` into Claude Code.

## What is included

- `CLAUDE.md` — permanent project instructions for Claude Code.
- `PASTE_INTO_CLAUDE_CODE.txt` — the exact first prompt to paste.
- `PROJECT_CONTEXT.md` — the conceptual center of the film.
- `VISUAL_RULES.md` — visual direction derived from the completed mood board.
- `TECHNICAL_BRIEF.md` — recommended p5.js, JavaScript, shader, and Python architecture.
- `TREATMENT.md` — clean text version of the full working treatment.
- `source/We_Only_Get_the_Wings_Working_Treatment.docx` — the original treatment.
- `references/moodboard_raw/` — 11 screen captures collectively documenting the 42 pins in the completed mood board. These are 42 visual references, not 11 references.
- `references/moodboard_contact_sheet.jpg` — a single overview of the board.
- `references/PINTEREST_BOARD.md` — the verified Pinterest URL, included as a supplemental link only.
- `assets/artwork/` — the future home for high-resolution scans and photographs of original materials.
- `output/` — intended destination for tests, frames, and exports.

The rejected earlier storyboard and its visual language are intentionally not included.
