# Start Here

1. Unzip this folder.
2. Open the entire `Claude_Code_Handoff_We_Only_Get_the_Wings` folder in Claude Code. Do not open only one file.
3. Open `PASTE_INTO_CLAUDE_CODE.txt`, copy all of it, and paste it into Claude Code.
4. Claude must first analyze the treatment and all 42 pin references visible across the 11 mood-board captures. It should create `VISUAL_INVENTORY.md` and `TECHNIQUE_MAP.md` before it writes animation code.
5. Read those two analysis files. If the reading of the mood board feels right, tell Claude to continue with the first motion study.
6. Review the 8–12 second study before permitting Claude to expand into the complete film.

You do not need to attach the treatment or mood board separately; they are already inside this folder.

Do not rely on Claude opening the Pinterest URL. Pinterest can require a session, hide pins behind sign-in, or expose only part of a board to automated tools. The local screen captures are the required visual source. The link is included only for human checking and optional supplemental access.

Later, place high-resolution photographs or scans of your own paintings, fabric, thread, paper, pearls, metal, and constructed objects in `assets/artwork/`. Those should become the actual surface material of the final film.
