# Original Artwork Assets

Place Toni's high-resolution original material here when available. Useful sources include:

- Full paintings and cropped painted fragments.
- Raw and stretched canvas.
- Woven fabric, loose fibers, thread, knots, and seams.
- Handmade paper, rubbings, stains, and drawn marks.
- Pearls, metal, wire, ceramic, translucent cloth, or constructed objects.
- Front-lit and side-lit photographs that preserve surface relief and cast shadow.
- Clean alpha-isolated fragments when appropriate, plus uncropped source photographs.

Keep original files intact. Runtime conversions, masks, and derived textures should be generated into a separate working directory by scripts. Record scale, lighting, and source information when possible.
